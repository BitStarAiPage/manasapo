# まなサポ｜Claude Code 制作指示

このフォルダは、採用したデザインと承認済み原稿をもとに、まなサポのホームページを制作するための引き継ぎ資料です。まだWebサイトのソースコードは含まれていません。

## ユーザーの使い方

1. ZIPを解凍してできた `manasapo-handoff` フォルダを、制作したいプロジェクトフォルダの中に置いてください。新規なら、空のプロジェクトフォルダを作って、その中に置きます。
2. そのプロジェクトフォルダでClaude Codeを開いてください。
3. 次の文を、そのまま送ってください。

> manasapo-handoff/START_HERE.md を読んで、まなサポのホームページを制作してください。採用済みの見た目は references/approved-design.png、本文は CONTENT.md を基準にし、DESIGN.md の要件を守って実装してください。まずローカルで確認できる状態まで進め、写真とフォームの未接続箇所を教えてください。

以下はClaude Codeへの制作指示です。

## 制作するもの

北海道岩見沢市の学習塾「まなサポ」のレスポンシブなトップページを制作してください。対象は小学生・中学生・高校生とその保護者です。ゴールは、教室の雰囲気・学び方を育む方針・コース・講師・生徒の変化が伝わり、無料体験・問い合わせの入口が分かることです。

提案だけで終わらず、既存のリポジトリを確認して実装し、ローカルで表示できる状態まで仕上げてください。

## 最初に読むもの

1. 対象リポジトリの既存ガイド・設定・依存関係を確認する。
2. `references/approved-design.png` を画像として開く。
3. `references/logo.png` を確認する。
4. `DESIGN.md` と `CONTENT.md` を全文読む。

## 優先順位

- **文章・事実・リンク：`CONTENT.md` が正。** 先方チェック済み原稿を勝手に要約・改稿しない。生成画像の小さな文字をOCRして本文に使わない。
- **レイアウトとトーン：`references/approved-design.png` と `DESIGN.md` が正。** ユーザーはこの画像の構成を了承している。
- **ロゴ：`references/logo.png` が正。** トレースやAI生成で作り直さず、その画像を使う。
- **写真：後日ユーザーが支給・差し替え。** 採用画像中の人物・教室は架空の仮画像。切り出して本物の教室・スタッフ写真として使わない。
- 生成画像で省略された本文は、`CONTENT.md` から補う。文字量が増えたぶん、セクションの高さを広げる。
- 採用画像にあっても、原稿にない文言・実績・スタッフ氏名などは追加しない。

## 実装環境

既存プロジェクトがあれば、フレームワークやパッケージマネージャーは既存に合わせる。新規で何も指定されていなければ、Next.js App Router + TypeScript + Tailwind CSSを初期案とする。プロジェクトを作る際は、引き継ぎ資料を消したり上書きしたりしない。

過剰なアニメーションライブラリやCMSは初期段階では不要。更新内容・コース・講師・写真パスは、コンポーネントから分離したデータで管理し、ユーザーが後から差し替えやすくする。静的な説明部分まで全てクライアントコンポーネントにしない。

## 作業順序

1. 必要ファイルを読み、採用デザインの特徴と実装方針を短く整理する。
2. 配色、見出し、ボタン、コンテナ幅、写真枠など共通スタイルを作る。
3. 最も重要なヘッダーとFVを先に作る。
4. 指定順序ですべてのセクションと承認済み全文を実装する。
5. コースへのページ内移動、受講例の折りたたみ、メニュー、フォーム入力を動かす。
6. モバイル対応を行い、写真未支給でもレイアウトが崩れない状態にする。
7. 利用可能な環境でビルド・型チェック・PC/SPの表示確認を行う。表示を確認できない場合は、その制限を明記する。
8. 起動方法、変更ファイル、写真の差し替え場所、未接続の機能、原稿の要確認箇所を短く報告する。

## 今回の完成範囲

まずローカルで確認できるWebサイトを制作する。公開環境へのデプロイや本番フォームの接続は、この引き継ぎだけで実施しない。すでにユーザーが別途公開や接続を依頼している場合は、その依頼範囲に従う。

フォームの送信先やAPIは未確定。見た目とバリデーションは作り、実際の送信が未接続の状態では「送信完了」と表示しない。メールアドレスが原稿にあっても、それだけでメール送信機能が完成したとは扱わない。

## 納品時の確認

- 巨大なキャッチコピー、黄色の面、写真の重なり、黒い特徴セクションが再現されているか。
- 普通の小さなカードを等間隔で並べたサイトになっていないか。
- 見出しを画像にせず、検索・読み上げ・選択が可能なテキストで実装しているか。
- `CONTENT.md` の全文が表示または展開可能な状態で含まれているか。
- 最新情報、スタッフ、写真の未支給箇所に架空の事実を入れていないか。
- 公開前の未確定事項を、サイト訪問者向けの文言に紛れ込ませていないか。

詳しいレイアウト、写真枠、実装上の注意は `DESIGN.md` を参照してください。
